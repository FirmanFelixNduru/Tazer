# Wave 4 · Staging dan APK release Rp 0

1. **Supabase Free.** Buka SQL Editor project `tazer-db` dan jalankan sekali [migrasi entitlement](../backend/supabase/migrations/20261125000000_entitlement.sql). Buat akun uji terverifikasi dan tetapkan tier `PRO` atau `BYOK` lewat `account_entitlements`. Akun tanpa row memakai tier `FREE`.
2. **Supabase Auth.** Aktifkan email dengan konfirmasi dan pemulihan, serta provider Google. Daftarkan URL callback HTTPS Supabase pada klien Google OAuth. Di URL Configuration → Additional Redirect URLs, tambahkan pola `tazer://auth/callback\?state=*` agar query PKCE `state` cocok dengan allowlist. Pastikan tautan email mengembalikan pengguna ke redirect yang diminta. [Redirect Supabase](https://supabase.com/docs/guides/auth/redirect-urls) · [Google OAuth Supabase](https://supabase.com/docs/guides/auth/social-login/auth-google)
3. **Cloudflare Workers Free.** Dari `backend/`, jalankan `npm ci`, `npx wrangler login`, lalu `npx wrangler deploy --keep-vars`. Set variabel publik `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, `GEMINI_MODEL`, dan opsional `GROQ_MODEL` di dashboard Worker. Isi `SUPABASE_SECRET_KEY`, `GEMINI_API_KEY`, dan opsional `GROQ_API_KEY` dengan `npx wrangler secret put NAMA_KEY` atau dashboard. Gunakan project provider free tier dengan billing nonaktif. [Wrangler](https://developers.cloudflare.com/workers/wrangler/commands/) · [Worker secrets](https://developers.cloudflare.com/workers/configuration/secrets/)
4. **Uji staging.** Set `TAZER_SUPABASE_URL`, `TAZER_SUPABASE_PUBLISHABLE_KEY`, dan `TAZER_BACKEND_URL` pada environment build Android. Uji email/Google, reset kata sandi, tier dan kuota, analyzer Gemini, fallback Groq bila tersedia, dan BYOK. Uji juga permission, Doze, pemulihan sesi, dan Smart Shift di HP fisik.
5. **Signed APK Release.** Dari Android Studio, pilih **Build → Generate Signed App Bundle or APK → APK → release** dengan keystore Tazer. Simpan keystore dan sandinya di luar repo dan gunakan keystore yang sama untuk pembaruan. Jalankan `apksigner verify --verbose` terhadap APK akhir lalu instal di HP uji. Distribusikan via sideload atau GitHub Releases gratis. [Penandatanganan APK Android](https://developer.android.com/studio/publish/app-signing)
